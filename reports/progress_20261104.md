## Local/API execution workflow

Added [a manifest-based runner](../src/run_evaluation.py) that uses the same hash-verified audio inputs for local Whisper and hosted `whisper-1`. It reuses the existing local model loader, decoder and checkpoint logic; the original five-clip output file remains unchanged.

- Default is a dry-run: verifies WAV hashes/metadata and reports coverage without model inference, API authentication or transcription calls.
- Actual execution requires `--execute`. Hosted execution additionally requires an explicit positive `--max-requests` limit for new calls in that invocation. The limit is a request count, not a verified monetary ceiling.
- Hosted requests use `whisper-1`, verbose JSON and temperature zero, with no language/ref-derived hint. SDK retries are zero; failed, pending or unparseable responses stop for investigation. A timeout may still have been processed. Error exports omit keys, headers and exception messages.
- Each attempt is checkpointed before execution; returned raw responses are saved before parsing/scoring. Successful empty transcripts count as deletions. API/compute errors remain coverage failures, with no invented ASR score.
- A per-output lock prevents overlapping executions; a stale lock after a crash requires investigation, not automatic deletion. Complete reruns reproduce metrics from saved responses without loading the model or authenticating to the API.
- Exports include per-clip and corpus normalized/raw WER/CER, coverage and failures. Incomplete conditions receive no headline WER/CER.
- Held-out execution additionally requires a manifest explicitly marked `frozen_for_inference: true` after the reference audit. That flag records a research decision; it does not independently prove that human review was performed.

Checked request serialization using the real pinned OpenAI SDK and an **in-memory HTTP mock transport**, as well as simulated success, empty output, interruption, rate limit and malformed responses. **No real API request was sent and no API key or balance was checked.** Actual account access/rate limits still need verification before the paid run. The request format follows the [official OpenAI transcription reference](https://developers.openai.com/api/reference/python/resources/audio/subresources/transcriptions/methods/create).
