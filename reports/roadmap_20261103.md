## Deliverable and scope decisions

The deliverable is a reproducible observational benchmark asking how reference CMI is associated with mixed-script transcription errors in local versus hosted Whisper. A flat, weak, or inconsistent relationship is a valid finding. Completion does not mean proving that English mixing causes errors, isolating a causal hosting effect, publishing a peer-reviewed paper, or training a new model.

The required version-1 systems are local Whisper `large-v2` and the hosted `whisper-1` API on the same eligible CS test clips. Large V2 is the proposed closest published generation/family match to the API's documented Whisper V2 foundation, not a guarantee of identical weights or decoding. Start local validation with faster-whisper FP16, batch size one; pin the runtime/model revision and precision before test inference. Freeze automatic-language settings with no reference-derived prompts. Keep earlier V3 Turbo and Google pilots separate from held-out evaluation. Existing saved Whisper API pilot predictions can be reused for the local five-clip compatibility comparison.
